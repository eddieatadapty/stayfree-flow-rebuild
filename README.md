# StayFree Growth Audit

**Live → https://eddieatadapty.github.io/stayfree-flow-rebuild/**

Five ideas to turn more StayFree users into subscribers, each built into a clickable version of StayFree's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | A spot before any form | +10–20% CR to purchase |
| 02 | Name their answer on the paywall | +10–15% CR to purchase |
| 03 | Ask for the account last | +5–10% CR to purchase |
| 04 | Show the year as $19.99, not $1.67 | +5–10% ARPU |
| 05 | Catch the ones who close | +5–10% CR to purchase |

Every price, rating and feature comes from StayFree's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for StayFree. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
